Glossario Tecnico P2P

Terminologia essenziale per comprendere le reti peer-to-peer e il Web decentralizzato.

Termini disponibili: 8 Filtra per categoria:
Peer (Nodo)
Ogni computer della rete che agisce sia come client che come server, senza gerarchia. Ogni nodo è contemporaneamente fornitore e consumatore di risorse.
Concetto Base
DHT (Distributed Hash Table)
Struttura dati distribuita che associa chiavi a valori senza server centrale. Usata in BitTorrent per trovare peer senza tracker centralizzati.
Protocollo
Seeder / Leecher
Il Seeder condivide il file completo; il Leecher lo sta ancora scaricando. Il rapporto Seeder/Leecher determina la velocità di download.
Comportamento Utente
Tracker
Server che aiuta i peer a scoprirsi all'interno di uno swarm. Mantiene una lista di indirizzi IP dei peer che condividono lo stesso file.
Infrastruttura
Magnet Link
Link basato sull'hash crittografico del contenuto invece che sulla sua posizione. Permette di scaricare file senza file .torrent.
Standard
Churn Rate
Frequenza con cui i peer entrano ed escono dalla rete. Un alto tasso di churn può ridurre la stabilità e la disponibilità dei file.
Dinamica di Rete
Swarm (Sciame)
Gruppo di peer che condividono lo stesso file nello stesso momento. Più grande è lo swarm, più veloce è il download.
Organizzazione
IPFS
Protocollo P2P per rendere il web distribuito, sicuro e resistente alla censura. Sostituisce il modello client-server con un sistema basato sul contenuto.
Web3
Blockchain
Registro distribuito immutabile che registra transazioni su una rete P2P. Ogni blocco è collegato crittograficamente al precedente.
Protocollo
Crittografia End-to-End
Sistema di sicurezza in cui solo gli utenti comunicanti possono leggere i messaggi. I dati sono criptati sul dispositivo del mittente e decriptati solo su quello del destinatario.
Sicurezza
Rete Mesh
Topologia di rete in cui i nodi si connettono direttamente, dinamicamente e non gerarchicamente a tanti altri nodi possibili.
Topologia
Smart Contract
Contratto auto-eseguibile scritto in codice su una blockchain. Si attiva automaticamente quando vengono soddisfatte condizioni prestabilite.
Web3
