Glossario Tecnico P2P

Terminologia essenziale per comprendere le reti peer-to-peer e il Web decentralizzato.

🖥️ Peer (Nodo)
Ogni computer della rete che agisce sia come client che come server, senza gerarchia.
Concetto Base
🔍 DHT (Distributed Hash Table)
Struttura dati distribuita che associa chiavi a valori senza server centrale.
Protocollo
🌱 Seeder / Leecher
Il Seeder condivide il file completo; il Leecher lo sta ancora scaricando.
Comportamento Utente
📡 Tracker
Server che aiuta i peer a scoprirsi all'interno di uno swarm.
Infrastruttura
🧲 Magnet Link
Link basato sull’hash del contenuto invece che sulla sua posizione.
Standard
🔄 Churn Rate
Frequenza con cui i peer entrano ed escono dalla rete.
Dinamica di Rete
🐝 Swarm (Sciame)
Gruppo di peer che condividono lo stesso file nello stesso momento.
Organizzazione
🌐 IPFS
Protocollo P2P per rendere il web distribuito, sicuro e resistente alla censura.
Web3
